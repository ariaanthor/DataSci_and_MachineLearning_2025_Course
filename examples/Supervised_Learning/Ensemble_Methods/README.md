# Ensemble Methods

This notebook demonstrates **ensemble learning methods** for supervised learning, focusing on how combining multiple models can improve predictive performance and robustness compared to a single estimator.

## Contents

* Overview of ensemble methods and motivation
* Training ensemble models (e.g., bagging / random forests / boosting)
* Comparison between individual base learners and ensemble performance
* Model evaluation using standard metrics
* Discussion of key hyperparameters and trade-offs

## Data

The notebook uses a **publicly available tabular dataset** with numeric input features and a continuous target variable. The data is loaded directly through standard Python libraries, preprocessed minimally (train/test split and basic cleaning), and is intended to clearly illustrate the benefits of ensemble techniques rather than domain-specific feature engineering.

## Requirements

* Python 3.x
* NumPy
* Pandas
* scikit-learn
* Matplotlib

## Usage

Run the notebook sequentially from top to bottom. All data loading and model training steps are self-contained, and no external configuration is required.

## Goal

The goal of this notebook is to provide an **intuitive and practical introduction** to ensemble learning, highlighting why and when ensembles outperform single models.
