# Logistic Regression

This notebook introduces **logistic regression** as a fundamental method for **binary classification**, focusing on intuition, implementation, and model interpretation.

## Contents

* Overview of logistic regression and the logistic (sigmoid) function
* Binary classification setup and label encoding
* Training a logistic regression model
* Interpreting model coefficients and decision boundaries
* Evaluating performance using classification metrics (accuracy, precision, recall)
* Discussion of model assumptions and limitations

## Data

The notebook uses a **publicly available tabular dataset** suitable for binary classification, with numeric input features and a binary target label. The data is minimally preprocessed and split into training and testing sets to clearly demonstrate how logistic regression models class probabilities and decision boundaries.

## Requirements

* Python 3.x
* NumPy
* Pandas
* scikit-learn
* Matplotlib / Seaborn

## Usage

Run the notebook sequentially from top to bottom. All data loading, preprocessing, and evaluation steps are self-contained.

## Goal

The goal of this notebook is to provide an **intuitive and practical introduction** to logistic regression, highlighting how linear models can be adapted for classification problems.
