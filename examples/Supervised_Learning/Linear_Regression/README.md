# Linear Regression

This notebook introduces **linear regression** as a foundational supervised learning method, emphasizing both conceptual understanding and practical implementation using real-world data.

## Contents

* Overview of linear regression and model assumptions
* Exploratory analysis of features and target variable
* Training a linear regression model
* Interpreting model coefficients
* Evaluating performance using standard regression metrics
* Brief discussion of limitations and sources of error

## Data

The notebook uses the **Ames Housing dataset**, a publicly available dataset containing detailed information about residential homes in Ames, Iowa. Each row corresponds to a house sale, with features describing structural properties (e.g., living area, number of rooms, year built) and the target variable representing the **sale price**. The dataset is well-suited for regression tasks and is commonly used for teaching and benchmarking predictive models.

## Requirements

* Python 3.x
* NumPy
* Pandas
* scikit-learn
* Matplotlib / Seaborn

## Usage

Run the notebook from top to bottom. The dataset is loaded locally from the provided CSV file, and all preprocessing and modeling steps are self-contained.

## Goal

The goal of this notebook is to provide a **clear and interpretable example** of linear regression applied to real housing data, serving as a baseline for more advanced models.
