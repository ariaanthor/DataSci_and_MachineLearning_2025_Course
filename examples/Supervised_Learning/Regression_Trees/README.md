# Regression Trees

This notebook demonstrates **regression trees**, a nonparametric supervised learning method that models nonlinear relationships through recursive partitioning of the feature space.

## Contents

* Overview of regression trees and recursive splitting
* Training a regression tree on tabular data
* Interpreting tree structure and predictions
* Evaluating performance using standard regression metrics
* Discussion of overfitting, depth control, and model limitations

## Data

The notebook uses a **publicly available tabular regression dataset** with numeric input features and a continuous target variable. The data is minimally preprocessed to focus on the behavior of tree-based models rather than feature engineering.

## Requirements

* Python 3.x
* NumPy
* Pandas
* Matplotlib
* scikit-learn (or equivalent tree implementation)

## Usage

Run the notebook from top to bottom to show model training, prediction, and evaluation.

## Goal

The goal of this notebook is to provide an **intuitive and practical understanding of regression trees**, highlighting how tree depth and splitting decisions affect predictive performance.
