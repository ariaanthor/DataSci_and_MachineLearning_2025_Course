# Decision Trees

This notebook provides an introduction to **decision trees**, covering both the theoretical intuition and a practical implementation using publicly available Python libraries and datasets.

* Python 3.x
* NumPy
* Pandas

## Usage

Run the notebook top to bottom. All datasets used are loaded automatically, and no external configuration is required.

The goal of this notebook is to provide a **clear, educational demonstration** of how decision trees work and how they are applied in practice.
